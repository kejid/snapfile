Snapfile is ready

Drag to capture an area — straight to your Downloads.

How to use

  1. Click the Snapfile icon, or press Alt+Shift+S
  2. Drag to select an area (resize with the handles, drag the middle to move)
  3. Click Save or press Enter — the PNG lands in your Downloads
  4. Esc cancels anytime
Default shortcut: Alt+Shift+S

One-time setup for truly instant saves

Snapfile never forces a dialog. But Chrome has a global setting that asks where to save every download — if it's on, you'll see a “Save as” window each time.

For instant, no-click saving, turn off:
“Ask where to save each file before downloading”
Opens chrome://settings/downloads. We can't change this setting for you — Chrome only lets you toggle it yourself.
You can reopen this page anytime from the extension's Options.
